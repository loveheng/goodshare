# goodshare · Android 分享收集器 + 内嵌 MCP 服务

## 目标
- 手机使用过程中，通过系统分享菜单把「好东西」（文本 / 链接 / 图片 / 视频 / 文件）一键收集进 app
- app 内可作为 MCP 服务（Streamable HTTP）运行，供桌面 AI 客户端（Claude Desktop / ZCode 等）检索与读取收集内容
- 链路：采集（分享菜单）→ 存储（sqflite）→ 浏览检索（Flutter UI）→ MCP 对外（tools）

- [2026-09-27] 存储：sqflite 单表 items + path_provider；图片/视频/文件复制进 app 私有目录（documents/shares/），不依赖源 app 的 content URI（防撤销/失效）
- [2026-09-27] MCP 传输：dart:io HttpServer 内嵌监听 0.0.0.0:8765，手写 Streamable HTTP + JSON-RPC 2.0（initialize / tools/list / tools/call / ping）；支持协议版本 2025-06-18 与 2025-03-26；GET/DELETE /mcp 返回 405（v1 无服务端主动推送）
- [2026-09-27] MCP 工具集 v1：`list_items`（分页/类型过滤/关键词）、`get_item`（全文；图片返回 base64 image 内容块，超大文件只给路径）、`add_item`（AI 侧写入文本/链接）

- [2026-09-28] 单一写路径闭环：AI 管线（`QueueConsumer`）当前直写 `_repo.update`，绕过 `ItemActionHandler` 校验——AI 产出的 `machine_json` 未过领域 Schema（潜在脏数据），重分类特权未显式化。决策：新增 `ItemActionHandler.applyAiResult(itemId, ReconstructResult, {aiPrivilege:true})` 特权入口，管线改调之；内部对 `machine_json` 同样过 `validateMachineJson`，并以显式 `aiPrivilege` 保留 AI 重分类特权（V2 §3.8 语义），落库仍走 `_repo.update` 复用 `notifyListeners`。UI / MCP / AI 三线写全部收口到 `ItemActionHandler`。动因：闭合「写必走 Handler」灵魂原则，并顺带堵住 AI 产出 machine_json 未校验的隐患。

- [2026-09-28] 第 3 档「后台常驻引擎」落地（前台服务共享 + 设备状态感知调度，用户推进）：决策——不把 `QueueConsumer` 搬到 `flutter_foreground_task` 的 task isolate。事实依据：该插件**仅支持单个前台服务**，而 `McpController.enable()` 已用它保活主 isolate（`startService` 无 callback，`eventAction: nothing`，McpServer/QueueConsumer 都在主 isolate 跑）；搬 consumer 进后台 isolate 需另开 sqflite 连接且与主 isolate 双写竞争。故取更稳路径：**复用同一前台服务保活主 isolate**，退后台时 consumer 的 3s 轮询继续消费。由此派生硬约束：`init` 收敛到 `lib/service/foreground_task_init.dart` 的 `ensureForegroundTaskInit()` 幂等统一执行（MCP/AI 各自只 `startService`），`stopService` 前必查 `mcp.running` 以免打掉 MCP 服务。调度按 V2 §3.x 落地：充电/满电/电量≥40% 且非内存压力才认领任务，否则停留 `pending`（非 failed）；`onMemoryPressure`（Flutter `didHaveMemoryPressure`）触发时暂停+回滚 pending 待续跑、不崩溃。动因：用户原规划「flutter_foreground_task 作为第 3 档（复杂离线模型推理、大批量媒体索引）的后台常驻引擎备用」。
- [2026-09-28] 库表/新增依赖决策：`Repository.pendingCount()`（通知栏进度），`QueueConsumer.canProcess` 可选门控字段（不进构造函数，避免破坏既有 3 参调用与单测）；`battery_plus ^7.1.1`（要求 Flutter ≥3.22 / Dart ≥3.4，本机 Flutter 3.47 / Dart 3.13 满足）。

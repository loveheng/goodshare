# 详情页视觉层级（排版疏密，方案蓝本，未实现）

> [!NOTE] 状态：**draft**——2026-10-02 交互评估对话定稿，与 `card-batch-selection.md` / `block-format-input.md` / `quick-note-draft.md` 同属整体改造蓝本族；落地验收后转 active。

## 1. 背景与已修部分

用户反馈详情页「排版太满、区块标题与正文没区分度、贴边」。排查结论：**三处观感对应一个 bug + 一个设计断层**。

- **bug（已修复，2026-10-02）**：`item_detail_page.dart` 的内容留白 `SliverPadding` 自 sliver 虚拟化重构起就是**无 sliver 子项的死代码**（静默零渲染），`Insets.xl` 水平留白从未生效，正文一直贴屏幕边缘。已补 `sliver: SliverMainAxisGroup(...)` 真正包住内容（devlog 2026-10-02，lesson 已记）。
- **设计断层（本文档待实现）**：灵感区分区头（摘要/标签/灵感）手写 `labelMedium` + `onSurfaceVariant` 灰小字——与卡片元信息行同级、无字重与结构对比；且绕开了 `SectionLegendCard` 骑框签 SSOT（其注释明言「详情页正文类分区共用此组件，禁止各自手写」），同一页出现两套分区语言。

## 2. 待实现项

> 落地状态：第 1、2 项与 §3 便签标题槽已于组合H 2026-10-02 落地；第 3 项真机验收待侧载（真机验收④）。

1. **灵感区三头换骑框签**：`_inspirationSection` / `_inspirationTextArea` 的裸 `Text` 头（摘要/标签/灵感）改为 `SectionLegendCard` 骑框签名形态，与公共区（TLDR/标签卡）统一为全页一套「签名式分区」语言。
2. **疏密度调档**：区块间垂直间距 `Insets.lg` → `Insets.xxl`；签名到内容的间距 `Insets.xs` → `Insets.sm`，给页面呼吸感。
3. **验收基准**：修改前后真机对照——正文不再贴边、同一页分区头只有一种形态、区块间距呼吸感明显；`flutter analyze` 0 issue。

## 3. 便签标题槽显示规则（2026-10-02 拍板，仅详情页生效）

背景：无标题便签在详情页顶栏显示「未命名」死占位（零信息 + 隐含催促感），违背便签「捕获优先、命名可选」的心智。

1. **回退链**：`human_title` 有值 → 主位显示用户标题；为空 → 标题位显示**创建时间**（绝对短格式，如「10月2日 14:35」，跨年带年份）——严禁相对时间（"5 分钟前"会过期）。
2. **时间降级**：用户输入标题后，时间由**既有元信息行**承担小标题角色，不新增行。
3. **去重**：无标题态（时间占标题位）时，同屏元信息行**隐藏时间**，杜绝同屏两遍。
4. **边界**：不回写 `human_title`（保持用户权威数据纯净，AI/MCP 侧可区分人起的名与自动显示）；卡片面不变（预览即标题，与元信息行零冲突）；标题长按编辑交互不变。

## 4. 边界

- 间距具体档位（xxl/sm）以真机观感为准微调，不回改本蓝本结构决策。
- 本改动只动详情页排版与标题槽显示，不碰任何写路径/命令；与四份蓝本无依赖，可随整体改造任意顺序插入。

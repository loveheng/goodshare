# 卡片长按批量选择模式（方案蓝本，未实现）

> [!NOTE] 状态：**draft**——2026-10-02 交互评估对话定稿的全量决策台账 + 三层抽象设计，作为整体改造的实施蓝本；样板页验收后转 active，届时 §8 未实现标注逐项清零。

## 1. 背景与目标

全 app 四处瀑布流卡片列表（全部页/搜索/工作区内/保险箱视图）共用 `ContentCard`，目前只有 `onTap` 进详情，无列表级批量操作；置顶能力完全缺失（无字段/无命令/无 MCP 工具）。本方案一次性补齐：**长按卡片 → 选择模式 → 底部批量操作栏**，并从数据层新建置顶能力。改造涉及 schema、动作层、MCP、UI 骨架四个层面，故整体设计、整体落地，不做零散补丁。

## 2. 交互规格（已拍板决策台账）

### 2.1 进入与退出（选择模式骨架）

| 项 | 决策 |
|---|---|
| 触发 | 长按任意卡片进入选择模式，**触觉反馈**，该卡片立即选中 |
| 选中视觉 | 2dp 品牌色描边，**无对勾圆标**（用户修正拍板） |
| 模式中点按 | 加选 / 减选（已选卡再点 = 取消该张，非打开详情） |
| 全选 | **不做**全选入口 |
| 底部空间 | 操作栏**取代**底部导航（全部/工作区/设置）、全部页底部输入条、工作区新建 FAB——取代而非叠放 |
| 顶栏 | 「已选 N · ✕」，✕ = 清空选择退出模式 |
| 返回手势 | 退出选择模式，**先于**页面 pop |
| 零选中 | 四动作按钮可见但**置灰**（不隐藏，避免跳动） |
| 下拉刷新 | 选择模式中**禁用** RefreshIndicator，退出恢复 |
| 动作完成 | 自动清空选择、退出模式、底部导航回归，Snackbar 反馈结果（含部分失败汇总） |

### 2.2 动作集（底部操作栏，图标+文字并排，删除项红色）

| 动作 | 单条语义 | 批量语义与注意 |
|---|---|---|
| 置顶/取消置顶 | `set_pin`（新建） | 批量置顶全量生效；混合态（选中含已置顶）只显示「置顶」 |
| 工作区 | `add_to_workspace` / `remove_from_workspace` | 弹工作区选择器整批加入；Vault 条目被动作层拒绝 → **部分成功必须报跳过数**，禁静默 |
| 保险箱 | `set_vault` | 文案随上下文：保险箱视图内为「移出保险箱」，且该视图不出现「移入」 |
| 删除 | `delete`（软删，30 天回收站） | **必须二次确认**，弹窗只报数量（「删除 N 条收集？」），不列条目预览 |

- 🔒 `editLocked` 条目：批量删除与单条**同口径**——动作层 `_delete` 不校验锁（只有 update 拦），已核实 `item_action_handler.dart:189`。
- 顶栏/操作栏**无**「取消」菜单项——取消是模式控件（✕ / 返回手势），不与四动作并列。

### 2.3 置顶语义（新能力）

- 排序：**全部页顶部独立 pinned 区**（瀑布流前置独立分区，非混排），置顶内部按 `pinned_at` 倒序。
- 生效范围：**仅全部页**；搜索/工作区内/保险箱视图不参与置顶排序。
- 数据层：`inbox_items` 加 `pinned_at INTEGER`（NULL=未置顶），schema 升版（**v18**，2026-10-02 已落地）。
- MCP：**本轮同步做 `set_pin` 工具**（与 `set_vault` 同模式：布尔 on），人机对称硬约束；`list_items` 返回结构同步携带置顶状态（对外契约变更需同步 `test/mcp_server_test.dart`）。

### 2.4 范围边界

- **双入口保留**：详情页底栏/`⋯` 面板现有保险箱/删除/工作区入口不动（列表管批量，详情页管单条完整操作）；但底层动作声明与执行通道统一接入词汇表（§3.2/§3.4），视觉与交互形态不变。
- 回收站页（最近删除）本轮**不接入**，已登记待办（恢复/彻底删除，彻底删除需强二次确认）。
- 本轮**样板页=全部页先行**，验收后铺搜索/工作区内/保险箱视图（届时仅加动作配置声明）。

## 3. 抽象设计（四层：词汇表/执行全共享，呈现分形态）

边界画在「**动作语义两端统一，呈现形态各回各家**」这条线上；严禁把动作语义通用化（组件自读条目状态决定菜单），也严禁把不同形态的栏合并成一个带配置开关的万能 ActionBar（god widget 反模式）。

### 3.1 选择模式骨架（`lib/ui/selection/`，写一次；词汇表的消费形态之一）

- `SelectionController<T>`：选中集合、进入/退出模式、清空。
- `SelectionModeScope`：内置手势协议（长按进模式+触觉、模式中点按加/减选、返回手势退出）、统一渲染底部操作栏与顶栏「已选 N · ✕」、与 `bottomNavigationBar` 的 `AnimatedSwitcher` 替换动画、列表底部 padding 随操作栏实际高度补偿（末排卡片不被遮）。
- `ContentCard` 只加三个可选参数：`selectable` / `selected` / `onLongPress`——卡片不知道「选择模式」的存在。

### 3.2 动作词汇表（`BatchAction`，两端共用）

```dart
BatchAction(
  id: 'set_vault', label: '移入保险箱', icon: Icons.lock_outline,
  danger: false,
  available: (ctx) => !ctx.inVaultView,          // 状态条件收录统一在此判定
  build: (ids) => /* ItemCommand */,             // 或纯 UI 回调（编辑/分享类）
)
```

- 词汇表是**全 app 动作唯一声明处**（2026-10-02 拍板纳入本轮）：列表批量菜单、详情页底栏、`⋯` 功能面板各自挑子集渲染，规则只写一份——editLocked 口径、Vault 拒绝提示、保险箱文案切换、机器码仅开关开，改一处两端生效，杜绝同一动作两套手写实现的规则漂移。
- 允许**回调型动作**（非 ItemCommand 的纯 UI 行为，如「编辑」进编辑态、「分享」调系统面板），不能一刀切全走命令。
- 四页配置：全部页/搜索页 = 全量四项；保险箱视图 = 去「工作区」+ 保险箱项换「移出」；工作区内页 = 全量四项（预留「移出本工作区」候选）。长按触发在骨架内定死，页面不再各自接手势。

### 3.3 执行与反馈收口（`BatchActionExecutor`，全共享）

操作栏点击 → 按动作把选中 id 映射为 `ItemCommand` → `ItemActionHandler.executeAll`（事务化批量入口已有；单条场景即单命令 `execute`）→ 统一处理：部分失败汇总反馈、完成钩子（退出选择模式 / 收起面板）、Snackbar + 底部导航回归。UI 不内联业务（goodshare-arch 硬约束），未来新增动作只是加一条 `BatchAction` 声明。

### 3.4 呈现策略（分形态，共享词汇表与执行）

同一词汇表三种消费形态，布局/动画/隐显逻辑各自实现，**不合并**为万能 ActionBar（god widget 反模式）：

| 形态 | 消费方 | 形态特有行为（留在各自呈现组件里） |
|---|---|---|
| 选择模式操作栏 | 列表批量菜单 | 模式耦合（取代导航/输入条/FAB）、零选中置灰、动作完成退出模式 |
| 详情页常驻底栏 | 详情页 | 方向感知隐显、错峰入场——**2026-10-02 已拍板形态不动**，仅底层声明与执行通道换接词汇表 |
| `⋯` 功能面板 | 详情页底栏子集展开 | 条件收录（机器码/保险箱文案）从手写 `_SheetItem` 迁到词汇表 `available()` 判定 |

## 5. 落地顺序（整体改造的分步切片）

1. 数据层：schema v18 + `pinned_at` 读写（已完成 2026-10-02） + 全部页置顶排序查询；
2. 动作层：`PinCommand` + `executeAll` 批量通道核验；
3. MCP：`set_pin` 工具 + 契约测试同步；
4. 词汇表先行：`BatchAction` 定义 + 执行器 + 详情页底栏/`⋯` 面板重接（视觉不动，先收规则漂移账）；
5. UI 骨架：`lib/ui/selection/` 三件套 + ContentCard 参数（以全部页为样板打通）；
6. 全部页样板：置顶独立区 + 四动作配置 + 让位矩阵（导航/输入条/FAB）联调；
7. 真机验收 → 铺其余三页（纯配置）→ 文档转 active。

## 6. 实现护栏

- 批量必须走 `executeAll`，严禁 UI 循环调单条命令。
- 触觉反馈 = 进入模式的信号，与既有 `HapticFeedback` 用法同口径。
- 瀑布流 pinned 区与 MasonryGridView 的衔接：pinned 区独立横滑行或纵向小网格，实现时以不破坏现有瀑布流高度计算为准（细节实现期定，不回改本台账决策）。
- 刷新/重载路径不得丢失选择集（刷新被禁用，但 `item` 对象重建时选中集合按 id 匹配）。
